# DPCO Glossary

- **Agent:** An LLM or autonomous AI model that reasons, plans, and formulates tasks for DPCO.
- **Capability:** A discrete, machine-readable operation supported by an executor (e.g., `algebra.linear.solve`).
- **DEAS-1:** DPCO External Executor Adapter Standard v1.
- **Evidence:** Verifiable test runs, formal proofs, or independent verification records supporting capability claims.
- **Admission Grant:** Cryptographically backed permission granting an executor specific roles (`PRODUCTION`, `NEGATIVE_CONTROL`).
- **Independent Verifier:** Autonomous checking subsystem operating independently from the producer executor.
- **USCA-1.0:** Universal Software Capability Architecture constitution.
