# DPCO Project Governance

## 1. Maintainers & Authority
DPCO is governed by the project owner (`a50kv109`). Final architectural decisions, major specification revisions (such as USCA and DEAS-1), and merge approvals to the main branch remain exclusively with the project maintainer.

## 2. Decision Making Process
- Architectural proposals are submitted via GitHub Issues or PRs following ADR (Architecture Decision Record) formats.
- Community feedback from developers and AI systems is evaluated based on mathematical rigor, verification independence, and scope discipline.
