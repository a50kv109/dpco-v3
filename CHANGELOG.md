# Changelog

All notable changes to DPCO will be documented in this file.

## [2.0.0] — 2026-11-08 (Public Architecture Baseline 2.0)
- Consolidated DPCO architecture into DPCO v2.
- Defined DEAS-1 Revision 1 asynchronous runtime contract.
- Established rigorous separation between IMPLEMENTED, TESTED, DESIGNED, and PROPOSED components.
- Standardized security, artifact exchange, independent verification, and evidence registries.

## [0.1.0] — Initial PoC
- Initial Python-based PoC implementation of arithmetic, linear system solvers, contradiction gates, and SHA-256 ledger.
